
# OfficeOS

A multi-tenant business management SaaS platform.

## Technology Stack

### Backend
- ASP.NET Core 10 Web API
- C#
- MongoDB

### Frontend
- React
- TypeScript

## Architecture

OfficeOS is being developed as a modular monolith with multi-tenant data isolation.
